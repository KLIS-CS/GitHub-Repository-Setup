# CP1 Task Sheet — Repository Setup

**Time target:** 25 minutes

## 1. Copy the official exercise

Use the official CP1 template:

[![Copy Exercise](https://img.shields.io/badge/COPY%20CP1%20EXERCISE-%E2%86%92-1f883d?style=for-the-badge&logo=github)](https://github.com/new?template_owner=KLIS-CS&template_name=GitHub-Repository-Setup&owner=%40me&name=cp1-repository-setup-YOUR-GITHUB-USERNAME&description=Checkpoint+1:+GitHub+Repository+Setup&visibility=public)

Create the copy in your own GitHub account and rename it exactly:

```text
cp1-repository-setup-YOUR-GITHUB-USERNAME
```

Example:

```text
cp1-repository-setup-octocat
```

Keep the repository **Public**.

## 2. CP1 rule — work on `main`

CP1 does **not** use a feature branch or Pull Request.

Complete the required files directly on the repository's default `main` branch. You may work in the GitHub web interface or locally.

Branch and Pull Request skills begin in CP2.

## 3. Complete the three assessed files

Your finished repository root must contain:

```text
README.md
.gitignore
LICENSE
```

### `README.md`

Replace the copied starter README with your own README. Your finished README must include:

- an H1 project title;
- a clear explanation of the repository;
- a **Setup**, **Usage**, **Getting Started**, **Installation**, or **How to Run** section;
- at least one useful instruction another developer could follow.

Do not leave the starter CP1 README unchanged.

### `.gitignore`

Create a `.gitignore` at the repository root with at least one real ignore rule appropriate for the project.

Examples:

```text
node_modules/
.env
.DS_Store
dist/
```

### `LICENSE`

Create a `LICENSE` file containing the complete text of a real open-source license such as MIT, Apache-2.0, or GPL-3.0.
