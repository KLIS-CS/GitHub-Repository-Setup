# Checkpoint 1 — Build a Professional Repository

## Goal

Show that you can set up the essential files of a professional repository and explain why each file exists.

## Required Branch

```text
cp1-YOUR-GITHUB-USERNAME
```

Example: `cp1-octocat`

## Challenge

Treat `project/` as the root of a brand-new project repository. Create all three files yourself:

```text
project/
├── README.md
├── .gitignore
└── LICENSE
```

Your `project/README.md` must contain a project title, explain what the project does, and include at least one setup or usage instruction.

Your `project/.gitignore` must contain at least one real ignore rule appropriate for a development project, such as `node_modules/`, `.DS_Store`, or `.env`.

Your `project/LICENSE` must contain a real open-source license text, not only the license name.

Complete `submission.md`, then run `git status`, commit your work on the required branch, push it to `origin`, and open a Pull Request to `main`. Leave the Pull Request open for grading.

## Scoring

- **60 points** — automatic Git/GitHub evidence
- **40 points** — teacher review of quality and reasoning
